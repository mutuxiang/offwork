# OffWork · 下班场景移动端交互原型

帮助用户「把下班时间还给自己」的移动端高保真交互原型，覆盖从关机那一刻到回家恢复的全流程：关机仪式、文字倾诉、待办封存、拉杆打烊、通勤白噪音、呼吸放松、逐件日程规划、恢复仪表盘。

## 版本

本仓库内容对应 **v14**（最新交付）。

## 如何运行

直接用浏览器打开 `OffWork-高保真交互稿-v14.html` 即可。该文件为**单文件、零外部依赖**——所有图标与插画已 base64 内联，无需联网，也无需本地服务器。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `OffWork-高保真交互稿-v14.html` | 可交互交付稿（自包含，双击即用） |
| `src/` | v14 源码：`app.v14.js` / `journey.v14.js` / `builder.v14.js` + `css/` 六套样式（layout / ritual / journey / builder / theme / vent） |
| `assets/` | v14 素材源图：呼吸屏相位图标 `breath/`、屏住时灰尘散点 `dust/`、白噪音面板图标 `gen/sound14/`、欢迎页插画 `gen/hero/` |

## 说明

本仓库仅包含 v14 交付内容（代码 + 素材 + 简介）。原型所需的全部图像已内联进 HTML；仓库内的 `assets/` 仅作为素材源文件留存，便于二次编辑与溯源。
