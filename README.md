# OffWork

把收工后的时间还给自己。当前版本更新于 **2026-10-18**，替换此前仓库中的旧原型与源码。

流程覆盖欢迎介绍、生活偏好、语音倾诉与情绪回应、明日待办、白噪音与呼吸训练、逐件安排今晚、活动卡片，以及个人时间回看。

## 本地运行

需要 Node.js 22 或更新版本，无需安装运行依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173 。也可以将仓库根目录交给任意静态文件服务器，入口为 `index.html`。

## 修改与构建

```sh
npm run check
npm run build
npm test
```

- 编辑 `src/app.js`、`src/styles.css`、`src/template.html` 后运行构建，更新根目录 `index.html`。
- 构建还会生成 `dist/offwork.html`：包含全部图片与字体的完整离线单文件，可直接用浏览器打开。`dist/` 是生成产物，不重复提交到 Git。
- `npm test` 使用本机 Chrome 或 Edge 的无头模式验证主要流程。找不到浏览器时可通过 `CHROME_PATH` 指定路径。
- `.github/workflows/check.yml` 会检查源码、素材完整性、构建结果与浏览器主要流程。

## 目录

| 路径 | 用途 |
| --- | --- |
| `index.html` | 最新可运行入口，可静态托管 |
| `src/template.html` | 页面外壳与预览导航 |
| `src/styles.css` | 最终视觉样式，保留样式分段以维持当前效果 |
| `src/app.js` | 全部交互与演示数据 |
| `assets/` | 从最终版本提取、按内容去重的图片、SVG 与字体 |
| `assets/manifest.json` | 素材类型、大小、SHA-256 和引用数量 |
| `scripts/` | 本地服务器、构建、素材检查、浏览器检查与单文件导入工具 |

素材采用内容哈希命名。更新素材时需同步修改源码引用和清单；`npm run check` 会检查文件与清单是否一致。若要导入另一份包含内嵌素材的完整原型，可运行：

```sh
node scripts/import-prototype.mjs /path/to/prototype.html
npm run build
```

## 原型范围

- 四个导航为 **收工 / 今晚 / 回看 / 设置**，设置页包含同页四张偏好卡片。
- 偏好、行程和演示状态保存在当前浏览器的 `localStorage`，可用页面上的“重新体验”清空。
- 倾诉按钮直接播放示例气泡与情绪回应，不访问麦克风，也不请求录音权限。
- 白噪音由浏览器 Web Audio 生成。备忘录导入为交互演示，尚未接入系统备忘录。
- 播客、晚饭、阅读、剧集及锻炼推荐页仍为占位，页面有明确的未开发说明。

本仓库仅保留最终运行代码、素材和维护脚本，排除了本地浏览器资料、调试截图、旧版本备份与一次性迭代脚本。
